# Игровая полка

Телеграм-бот + API для учёта игр.

## Возможности

- добавлять игры через бота
- смотреть список игр
- удалять игры
- просматривать список в браузере

## Как запустить

1. Установить зависимости:

pip install -r requirements.txt

2. Запустить API:

uvicorn main:app --reload

3. В bot.py вставить токен

4. Запустить бота:

python bot.py

## Команды бота

/start — список команд
/games — показать все игры
/delete — список для удаления
/delete 2 — удалить игру под номером
