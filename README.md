# Игровая полка

Телеграм-бот + API для учёта игр.

## Возможности

- У каждого пользователя свой список игр
- Добавление игр через бота
- Просмотр списка
- Удаление
- HTML-страница со списком

## Как запустить

1. Установить зависимости:

pip install -r requirements.txt

2. Запустить API:

uvicorn main:app --reload

3. В bot.py вставить токен

4. Запустить бота:

python bot.py

## Команды бота

/start — регистрация и команды
/games — мои игры
/delete — список для удаления
/delete 2 — удалить игру под номером
